# Reference material

This directory contains rulebook text sourced from the [Ars Magica Open License](https://github.com/OriginalMadman/Ars-Magica-Open-License)
markdown corpus, used here as reference material while building the covenant
builder app. It is **not** part of the shipped web app.

## Files

- `Ars Magica - Definitive Edition (Core Rules).md` — Ars Magica 5th Edition core rulebook.
- `Ars Magica 5e - Covenants.md` — the *Covenants* sourcebook.
- `arm5openlicenselogo.png` — Ars Magica Open License logo.
- `licenses/ARS-MAGICA-OPEN-LICENSE.md` — full text of the license these files are released under.
