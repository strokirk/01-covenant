# Reference Index for Covenant Builder

This file indexes the key sections from the *Ars Magica* rulebooks that support covenant design. The reference material is split into per-section chunk files in `reference/chunks/covenants/` (73 chunks from the *Covenants* sourcebook) and `reference/chunks/core/` (180 chunks from the Core Rules). Chunks are regenerated by `scripts/split-reference.mjs` and are git-ignored; to update them, edit the source Markdown files in `reference/` and rerun the split script.

This index points to the most relevant rules and tables for the app's features. When a chunk is too large for efficient lookup (e.g., laboratory personalization rules), skim by heading to find the specific table or rule you need.

## Not Needed for the App

The following chunks are out of scope for the covenant builder:

- **Spell lists** (core chunks 90–99: Animal, Aquam, Auram, Corpus, Herbam, Ignem, Imaginem, Mentem, Terram, Vim Spells). All spells follow spell design rules; individual spell stats are available in game references but not needed for covenant design.

- **Character creation & advancement** (core chapters 3–5: Characters, Virtues and Flaws, Abilities, and related chunks). Covenants are built by troupes, not individuals; magi creation is separate.

- **Combat & obstacles** (core chapter 11: Combat, Wounds, Fatigue, Travel, and related chunks). Not part of covenant design proper.

- **Bestiary** (core chapter 13: Creature Might, Powers, Format, Mundane Beasts, Creatures of Magic/Faerie/Infernal/Divine). Reference only; not needed for builder.

- **Magic theory deep dives** (core chapter 7 Hermetic Magic, including Limits of Magic, Dangers, Mysteries, etc.). Covered by library and vis source choices.

- **Storytelling & saga advice** (core chapters 14–16: Mythic Europe, Stories, Sagas). Flavor, not mechanics.

- **Administrative sections** (all credits, copyright, indices, editors' notes). Not needed for app logic.
